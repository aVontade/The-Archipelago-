# 🌊 The Archipelago

**The Ali family story — a century-long journey, told for this generation.**

*The Archipelago of Resilience* is the story of the Ali family: from the Comoros Islands to Mozambique, from a Johannesburg township to the far side of the sea. It is told as an heirloom — a story first, with the family's own artifacts as evidence.

---

## 📖 What's in this folder

| File | What it is |
|------|-----------|
| `index.html` | **The Passport** — the original presentation. Pages of the family's life, stamped with the world's history: 14 pages, 27 stamps, 2 voice notes, 10 photographs. |
| `story.html` | **The Story** — *The Archipelago of Resilience*. The comprehensive telling: 24 chapters in 6 parts, with the economic current running beneath it all. Includes 🌐 English/Portuguese translation and ⤓ PDF export. |
| `family-tree.html` | **The Family Tree** — six generations, 22 people, interactive. From G1 Comoros to G6. |
| `family_line_preview.png` | Preview image of the family line |
| `assets/` | All photographs, voice notes and transcripts |

## 🚀 How to publish

This folder is ready to push to **GitHub Pages** as-is:

```bash
# 1. Create a new repository on GitHub (public or private — your call)
# 2. From this folder:
git init
git add .
git commit -m "The Archipelago of Resilience"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/REPO-NAME.git
git push -u origin main
```

Then on GitHub: **Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save**.

Your site will be live at:
`https://YOUR-USERNAME.github.io/REPO-NAME/`

## 📜 The record

This presentation is built from the family's primary sources:

- **Mother's passport** — ALI-NEL, French national, issued Johannesburg 1958, renewed 1964–1967 (the years that bracketed a birth, a death, a handover, and a deportation)
- **The Family Tree (2013)** — the written record of three generations
- **Photographs** — the wedding, the wedding party, the sisters, the father with the daughter he knew and she never knew was her father
- **Voice notes** — Hamede's own voice: the first house in Ennerdale; Salazar, Georgie and Phillip
- **The Eulogy** — Phillip Winnaar, best man, brother, the redeemed one
